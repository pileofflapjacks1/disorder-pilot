# Prior art (searched and citation-verified 2026-11-05)

A research agent searched arXiv, ChemRxiv, the IUCr journals, JACS, GitHub and conference pages. A citation-verifier then checked each claim against the primary sources it could reach. IUCr and ChemRxiv pages returned 403, so the items marked *snippet* rest on search-index text.

## Bottom line

1. **LLM agents for single-crystal refinement exist.**
   - The only peer-reviewed one is NeuDiff Agent, which uses neutron data and was tested on one case.
   - For X-ray small molecules, they exist only as public code: CrystalPilot, materia-platform and shelx-mcp.
2. **Automated disorder *detection* exists only as unpublished code or claims:**
   - CrystalPilot generates candidates and checks splits.
   - Citrine has an R1-scored search, last updated in 2019.
   - RefrActor claims to resolve "moderate disorder".
3. **No benchmark found scores disorder false positives on ordered controls, or adjudicates disorder models by blinded experts.** The verifier's search turned up only this repository. The nearest work is CrystalPilot-TaskFullTest: one crystallographer reviewed 12 runs on 2 structures, with no blinding, no second reviewer, and no focus on disorder.
4. **R1 and the Hamilton test vs overfitting for disorder:** no study found, but classical Hamilton-test literature exists, and this claim has not been searched properly.

## What this means for the pilot's claims

- **Do not claim** the first LLM refinement agent, or the first automated disorder detection.
- **Defensible:** the first disorder detect-and-model benchmark that scores false positives on ordered controls and adjudicates disputed cases by blinded expert review, together with the finding that R1 cannot settle those cases. The R1 part should say "we found no prior study"; it has not been searched exhaustively.
- **Related work to cite:** CrystalPilot's disorder-candidate heuristics (a 0.4–1.6 Å peak window) are close to this pilot's rule-based baseline B (0.4–1.3 Å). A round-2 baseline could adopt them, as long as their non-commercial licence allows that use. Otherwise reimplement the idea from the description.
